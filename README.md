# µGUI para MicroPython

Este proyecto busca adaptar la biblioteca gráfica [µGUI](https://github.com/achimdoebler/UGUI), creada por Achim Döbler, para usarla desde MicroPython en microcontroladores.

## Objetivo

Implementar funciones básicas de dibujo y texto, y conectarlas con un controlador de pantalla. El consumo de memoria y el tiempo de dibujo se evaluarán en una placa de prueba.

## Estado

El proyecto está en su etapa inicial. Aún no cuenta con una implementación funcional ni instrucciones de instalación.
